아래는 요청하신 내용을 바탕으로 정리한 한자학습 모바일 앱(iOS / Android) 기획서 초안입니다.
기획의 기준 데이터셋은 한국 중·고등학교 한문 교육용 기초 한자 1,800자(중학교용 900자, 고등학교용 900자)이며, 사전형 상세 정보는 네이버 한자사전이 제공하는 항목 구조(예: 교육등급, 부수, 총획수, 단어/성어, 학습정보, 획순 정보)를 참조하는 방향으로 설계했습니다.  ￼

# 한자학습 모바일 앱 기획서
## 프로젝트명(가칭)
한자정습(漢字正習)

---

# 1. 프로젝트 개요

## 1.1 프로젝트 목적
한국 중·고등학교 교육용 기초 한자 1,800자를 체계적으로 학습할 수 있는 모바일 앱을 개발한다.  
본 앱은 단순 암기형 앱이 아니라, 다음의 3개 학습 축을 중심으로 설계한다.

1. **한자 정보 이해**
   - 한자의 음, 뜻, 부수, 총획수, 교육등급, 활용 단어, 성어/숙어, 유래 등을 학습
2. **획순 기반 필기 학습**
   - 사용자가 손가락 또는 펜으로 직접 한자를 써 보며 획순을 익힘
3. **반복 훈련과 성취 관리**
   - 오답, 미학습, 약한 한자를 반복 제시하여 장기 기억으로 전환

---

# 2. 기획 배경 및 필요성

## 2.1 문제 정의
기존 한자 학습 서비스는 대체로 다음 문제를 가진다.

- 한자 정보를 사전처럼 보여주지만 학습 흐름이 약함
- 획순 애니메이션은 있으나 실제 필기 채점이 정교하지 않음
- 중·고등 교육용 범위에 맞는 커리큘럼 구조가 부족함
- 단어, 숙어, 고사성어와 연결되는 실제 활용 학습이 약함

## 2.2 해결 방향
본 앱은 “정보 조회 + 직접 쓰기 + 반복 복습”이 하나의 UX 흐름으로 연결되도록 설계한다.

- 한자 1자 학습 → 뜻/음/부수/총획/유래 확인
- 획순 애니메이션 확인
- 동일 글자를 정사각형 쓰기판에 획순대로 직접 필기
- 성공/실패 판정 및 피드백
- 단어/성어/숙어로 확장 학습
- 주기적 복습

8.3 필기 학습 기능

목적

사용자가 손가락 또는 펜으로 직접 쓰며 한자를 체득하게 한다.

입력 수단
	•	손가락
	•	스타일러스 펜(Apple Pencil, S Pen 등)

필기 영역 규격
	•	화면 하단에 쓰기판 배치
	•	상단에는 한자 정보/획순/피드백 영역
	•	쓰기판은 내비게이션 영역을 제외한 하단 주요 영역을 차지
	•	한자는 정사각형 프레임 내부에서 작성

쓰기판 가이드 규칙

정사각형 내부를 다음 기준으로 구획한다.
	•	외곽 정사각형 경계선
	•	중앙 1/2 기준선: 파선
	•	1/10, 1/20 보조선: 점선
	•	학습용 기준축(가로/세로) 제공

글자 표시 규칙
	•	정답 예시 한자는 정사각형 내부 80% 크기로 표시
	•	회색 반투명 가이드 또는 외곽선 모드 지원
	•	초급 모드에서는 희미한 트레이싱 제공 가능
	•	숙련 모드에서는 빈 칸만 제공

필기 판정 규칙

획순 기반 판정은 다음 요소를 포함한다.
	1.	획 순서 일치 여부
	2.	획 방향 일치 여부
	3.	시작점/종점 허용 오차
	4.	꺾임/곡선 형태 유사성
	5.	상대 위치/비율 정확도
	6.	전체 자형 균형

판정 방식
	•	완전 정답
	•	부분 정답
	•	획순 오류
	•	형태 오류
	•	크기/위치 오류

피드백 예시
	•	“1획 시작 위치가 너무 아래입니다.”
	•	“현재 획은 가로획이 먼저입니다.”
	•	“3획 방향이 반대입니다.”
	•	“전체 비율은 좋지만 오른쪽 구성요소가 큽니다.”

학습 모드
	•	따라쓰기 모드
	•	획순 유도 모드
	•	자유 쓰기 모드
	•	시험 모드

실무 의견

초기 버전은 AI 필기 인식 전체를 도입하기보다, 정답 획 템플릿 기반 검증으로 시작하는 것이 적절하다.
이 방식이 구현 난이도, 설명 가능성, 학습 피드백 품질 면에서 유리하다.
이후 고도화 단계에서 온디바이스 ML 또는 서버형 필기 평가를 추가하는 것이 바람직하다.
