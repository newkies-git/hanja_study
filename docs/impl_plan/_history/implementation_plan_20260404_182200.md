## 1. 현황 요약
- **프로젝트 구조**: `flutter/chusa1817`을 중심으로 기능별(feature-based) 아키텍처가 잘 잡혀 있습니다.
- **주요 기술**: Flutter, Riverpod (상태 관리), go_router (라우팅), Drift (로컬 DB), Firebase (인증 및 동기화).
- **최근 진행**: 홈 화면 대시보드 고도화, 추천 복습 섹션(2열 그리드) 구현, 샘플 데이터 생성 기능 추가, 로컬 유저 프로필 및 활동 추적 시스템 구축.

## 4. 아키텍처 보완사항
- **테스트 커버리지**: UI 컴포넌트 및 로직 변경에 따라 기존 테스트 코드가 깨져 있습니다. 테스트 코드의 일제 정비가 필요합니다.
- **코드 정리**: 정적 분석에서 발견된 Lint 경고들을 해결하여 코드 품질을 높여야 합니다 (특히 통계 및 학습 화면).
- **동기화 안정성**: Firestore와의 데이터 동기화(`FirestoreContentSyncService`) 로직이 실제 대량 데이터 상황에서 안정적인지 추가 검증이 필요합니다.

## 5. 추가 개발 제안 (우선순위순)

### Phase 1 — 즉시 착수 (1~2주)
- **테스트 코드 정상화**: 실패하는 위젯 테스트 수정 및 핵심 로직(복습 알고리즘, 통계 계산) 단위 테스트 추가.
- **Lint 경고 해결**: 프로젝트 전체의 경고 사항을 정리하여 Clean Code 유지.
- **복습 알고리즘 정교화**: 현재의 `nextReviewAt` 산출 로직을 SM-2 알고리즘에 더 가깝게 튜닝.

### Phase 2 — 단기 (2~4주)
- **성취도 뱃지 시스템**: 학습 일수, 마스터한 한자 수 등에 따른 시각적 보상(Badge) 레이아웃 구현.
- **다크 모드 지원**: 프리미엄 UI 디자인에 맞춘 다크 모드 테마 추가.
- **검색 기능 강화**: 부수별, 획수별 필터링 기능 고도화.

### Phase 3 — 중기 (1~3개월)
- **AI 필기 인식 보완**: 단순 템플릿 비교를 넘어 온디바이스 ML을 활용한 더 유연한 필기 인식 도입 검토.
- **커뮤니티/공유 기능**: 학습 성과를 이미지로 생성하여 공유하는 기능.
