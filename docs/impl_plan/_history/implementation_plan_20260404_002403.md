# 프리미엄 벡터 붓 아이콘 업그레이드 계획

기존 이미지 파일(`brush_icon.png`)의 격자무늬 배경 문제를 완전히 해결하고, 100% 투명한 배경을 보장하면서도 예술적 디테일이 살아있는 **완전 벡터 방식의 `HanjaBrushIcon`**으로 업그레이드합니다.

## 제안 배경

> [!IMPORTANT]
> 이미지 파일 방식은 원치 않는 배경(격자무늬 등)이 포함될 수 있으나, **CustomPainter(벡터)** 방식을 사용하면 수학적으로 계산된 깨끗한 투명도를 보장하며 모든 해상도에서 선명합니다.

## 주요 변경 사항

### [공유 위젯] HanjaBrushIcon 업그레이드

기존의 `Image.asset` 호출 방식을 버리고, `CustomPainter`를 이용해 다음 요소들을 정교하게 구현합니다:

1.  **역동적인 S-자형 획 (Elegant Ink Stroke)**
    - 이미지에서 보았던 "통통하게 시작하여 날렵하게 빠지는" 유려한 곡선을 면(Fill)으로 드로잉.
    - 끝부분에 미세한 "갈라짐(Split)" 효과를 추가하여 먹의 생동감 부여.
2.  **정교한 붓촉 (Artistic Brush Tip)**
    - 붓털 하나하나가 느껴지는 세밀한 선(Stroke)들을 겹쳐서 표현.
    - 붓 끝의 날카로움과 붓대(Handle)와의 연결 부위의 볼륨감을 입체적으로 재현.
3.  **100% 투명 배경 & 자유로운 색상**
    - 배경 없이 객체만 렌더링하여 FAB의 어떤 색상 위에서도 완벽하게 조화.
    - 이미지 고유의 명암 대비를 유지하면서도 전체적인 톤을 조절 가능하게 설계.

#### [MODIFY] [hanja_brush_icon.dart](file:///Users/yutaek/zWorkSpace/zBasis/HANJA/flutter/chusa1817/lib/shared/widgets/hanja_brush_icon.dart)
- `CustomPainter`를 활용한 프리미엄 드로잉 로직 작성.
- 명암 조절을 위해 고정된 색상이 아닌 레이어별 투명도(Opacity) 적용.
