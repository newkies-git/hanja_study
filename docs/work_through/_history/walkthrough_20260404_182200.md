# Walkthrough: Sample Data for Recommended Review

I have implemented a "Seed Sample Data" feature to help you test the **'Today's Recommended Review'** section when it's empty.

## Changes Made

### 1. Database & Repository
- **Interface**: Added `seedSampleReviewHanja()` to `ProgressRepository`.
- **Implementation**: In `LocalProgressRepository`, I implemented logic to:
  - Find 5 Hanja that haven't been studied yet.
  - Create mock progress records with **20% accuracy** (1 correct out of 5 attempts).
  - Set `lastStudiedAt` to yesterday, so they appear as "recommended for review" today.

### 2. UI Components
- **RecommendedReviewSection**:
  - Added an empty state view with a placeholder icon.
  - Added a **"샘플 오답 데이터 생성" (Generate Sample Error Data)** button that only appears when the list is empty.
  - **Layout Change**: Updated the Hanja cards to display in a **2-column grid** (2 cards per row) for better use of space on the Home Screen.
- **HomeScreen**:
  - Connected the button to the repository and added logic to refresh the UI immediately after seeding.

## How to Verify
1.  Go to the **Home Screen**.
2.  Locate the **"오늘의 추천 복습" (Today's Recommended Review)** section.
3.  If it's empty, you will see a button: **"샘플 오답 데이터 생성"**.
4.  Click the button.
5.  The section should immediately populate with 5 Hanja items that were "failed" in your mock history.

> [!TIP]
> This is a one-way operation that adds local data. You can delete the app's local data or study these items to clear them.
