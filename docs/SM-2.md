  SM-2 알고리즘이란                                                                                                                         
                                                                                                                                            
  1970년대 Piotr Wozniak이 개발한 간격 반복(Spaced Repetition) 알고리즘. Anki 등 암기 앱에서 널리 사용됩니다.                               
                                                                                                                                            
  핵심 아이디어: 잘 아는 것은 늦게, 모르는 것은 빨리 다시 보여준다.                                                                         
                                                                                                                                            
  ---                                                                                                                                       
  현재 코드의 SM-2 구현 (local_repositories.dart:333)       
                                                                                                                                            
  ┌─────────────────────────┬──────────────────────────────┬────────┐
  │          변수           │             의미             │ 초기값 │                                                                       
  ├─────────────────────────┼──────────────────────────────┼────────┤
  │ n (reviewCount)         │ 연속 정답 횟수               │ 0      │
  ├─────────────────────────┼──────────────────────────────┼────────┤
  │ interval (intervalDays) │ 다음 복습까지 일수           │ 0      │                                                                       
  ├─────────────────────────┼──────────────────────────────┼────────┤                                                                       
  │ ef (easeFactor)         │ 난이도 계수 (쉬울수록 큰 값) │ 2.5    │                                                                       
  └─────────────────────────┴──────────────────────────────┴────────┘                                                                       
                                                            
  정답 시:                                                                                                                                  
  - n=0 → interval=1일                                      
  - n=1 → interval=6일                                                                                                                      
  - n≥2 → interval = interval × EF (지수적 증가)
  - n 증가, EF 미세 증가                                                                                                                    
                                                                                                                                            
  오답 시:
  - n=0으로 리셋, interval=1일                                                                                                              
  - EF -= 0.2 (하한 1.3)                                                                                                                    
   
  ---                                                                                                                                       
  현재 코드의 문제점                                        
                                                                                                                                            
  SM-2를 구현했지만 복습 조건이 SM-2와 연결되어 있지 않습니다.
                                                                                                                                            
  현재 복습 조건: mastered + accuracyRate < 0.5 + nextReviewAt <= now
                                                                                                                                            
  SM-2 정석이라면 조건이 nextReviewAt <= now 만으로 충분한데, accuracyRate < 0.5를 추가로 걸어서 mastered 상태라도 정확도가 50% 이상이면    
  복습 대상에서 제외되고 있습니다.                                                                                                          
                                                                                                                                            
  또한 status 로직:                                         
  // n >= 4 이면 mastered, 아니면 learning
  final String progressStatus = (isCorrect ? (n >= 4 ? 'mastered' : 'learning') : 'review_needed');                                         
  mastered가 되려면 연속 4회 정답이 필요한데, 이후 오답이 나와도 mastered 상태는 유지된 채 accuracyRate만 떨어집니다 — 그래서 accuracyRate <
   0.5 조건이 필요한 구조입니다.

  방식입니다.

⏺ 오답노트 개념                                                                                                                             
                                                                                                                                            
  복습 탭의 오답노트는 SM-2 기반 복습 스케줄과 무관한 별도 기능입니다.

  데이터 소스                                                                                                                               
                                                                                                                                            
  fetchTopErrorProneHanja(limit: 9999) — UserProgressTable 전체를 대상으로:
  - accuracyRate가 낮은 순 (오답률 높은 순)                                                                                                 
  - totalAttempts 내림차순 (시도 횟수 많은 순)                                                                                              
  - 상태 조건 없음 — unseen이 아닌 학습 이력이 있는 모든 한자                                                                               
                                                                                                                                            
  표시 내용                                                                                                                                 
                                                                                                                                            
  각 항목에 표시되는 정보:                                                                                                                  
  - 한자 + 음/뜻                                                                                                                            
  - AccuracyProgressRow (정확도 바)                                                                                                         
  - correctAttempts / totalAttempts 회 정답
                                                                                                                                            
  복습 탭의 다른 섹션과 차이                                                                                                                
                                                                                                                                            
  ┌────────┬─────────────────────┬──────────────────────────────────────────────┐                                                           
  │        │      오답노트       │         오늘의 복습 / 다가오는 복습          │                                                           
  ├────────┼─────────────────────┼──────────────────────────────────────────────┤
  │ 조건   │ 정확도 낮은 순 전체 │ mastered + accuracyRate < 0.5 + nextReviewAt │
  ├────────┼─────────────────────┼──────────────────────────────────────────────┤
  │ limit  │ 없음 (전수)         │ dailyGoal                                    │                                                           
  ├────────┼─────────────────────┼──────────────────────────────────────────────┤                                                           
  │ 스케줄 │ 없음                │ SM-2 nextReviewAt 기준                       │                                                           
  ├────────┼─────────────────────┼──────────────────────────────────────────────┤                                                           
  │ 목적   │ 취약 한자 수동 확인 │ 자동 복습 스케줄                             │
  └────────┴─────────────────────┴──────────────────────────────────────────────┘                                                           
                                                            
  즉, 오답노트는 "언제든지 내가 틀렸던 한자를 다시 보고 연습" 하는 수동 목록이고, 오늘의 복습/다가오는 복습은 SM-2 알고리즘이 자동으로      
  스케줄링한 목록입니다.
